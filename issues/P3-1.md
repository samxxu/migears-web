# P3-1 — The README describes the lifecycle as "before → HTTP method → after" …

## Finding / 问题

- EN: The README describes the lifecycle as "before → HTTP method → after" without noting that a short-circuiting resource-level `before()` skips the resource-level `after()` (the behaviour is pinned by a test).
- 中文: README 把生命周期写成「before → HTTP 方法 → after」，未说明资源级 before() 短路时会跳过资源级 after()（该行为已被测试固化）。
- Where / 位置: `src/AbstractResource.php:136-140 vs README:202,482`
- Verification / 验证: reproduced / 已实证

The README now carries the short-circuit note in both languages, right beside the lifecycle description: a resource-level `before()` that returns a `Response` skips both the HTTP method and the resource-level `after()`, while the global `after` hooks registered on `MiRest` still run because they wrap the whole dispatch.
  - 中文: **fixed**（`60e4f7e`）。README 在生命周期说明旁新增中英双语短路说明：资源级 `before()` 返回 `Response` 时，HTTP 方法与资源级 `after()` 都不执行；注册在 `MiRest` 上的全局 `after` 仍会执行，因为它们包裹整个分发过程。
