# P3-3 — MiRest::createResource() relies on autoload to find resource classes — …

## Finding / 问题

- EN: MiRest::createResource() relies on autoload to find resource classes — if a class name matches a file that has not been loaded yet and autoload fails silently, the behavior is undefined.
- 中文: MiRest::createResource() 依赖自动加载来找到资源类——如果类名匹配的文件尚未加载且自动加载静默失败，行为将不可预测。
- Where / 位置: `src/MiRest.php:62-70`
- Verification / 验证: static / 仅静态推断

## Thread

- 2026-09-28 · `reviewer — migears-full-review` · `open` — filed from the 5th round.
- 2026-10-01 · `owner — migears-web` · `fixed` — reproduced, then fixed in this pass. Re-graded P3 → P2: what the probe showed is a silent wrong result, not metadata drift. Probe outside the repository, through this module's own `vendor/autoload.php`: a base dir whose `/foo` file declares no class, plus an autoloader mapping that FQCN to a second tree, answered `status=200 body={"from":"elsewhere"}` — the route was served by a file the locator never found. `loadResourceClass()` `require_once`d the located file but never checked that the file declares the class, and `createResource()` then asked `class_exists($className)` with the autoloader on, so the autoloader could supply it. Neither half is reachable now: the located file must declare the class (`src/MiRest.php:284-296`) and `createResource()` asks with the autoloader off (`src/MiRest.php:313`). The same probe now returns `status=500 body={"error":"Internal Server Error"}`. Pinned by `MiRestTest::testResourceClassIsNotResolvedByTheAutoloader`, which fails without the fix (200 vs 500).
  - 中文: **fixed**——已复现，并在本次修掉。级别由 P3 上调为 P2：探针看到的是静默的错误结果，不是文档漂移。仓库之外的探针经由本模块自己的 `vendor/autoload.php`：baseDir 中 `/foo` 对应的文件不声明任何类，再注册一个把该 FQCN 映射到另一棵目录树的自动加载器，得到 `status=200 body={"from":"elsewhere"}`——请求由定位器从未找到的文件服务。`loadResourceClass()` 只 `require_once` 了定位到的文件，却从不确认该文件是否声明了这个类；`createResource()` 随后又用开着自动加载的 `class_exists($className)` 询问，于是自动加载器可以补上这个类。现在两条路都不通：定位到的文件必须自己声明该类（`src/MiRest.php:284-296`），`createResource()` 改为关闭自动加载再询问（`src/MiRest.php:313`）。同一探针现在得到 `status=500 body={"error":"Internal Server Error"}`。由 `MiRestTest::testResourceClassIsNotResolvedByTheAutoloader` 固定，去掉修复该用例即失败（200 对 500）。
